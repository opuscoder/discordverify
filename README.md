Бот для верификации участников Discord на Python. Пользователь нажимает кнопку,
вводит код с картинки и получает роль, открывающую доступ к серверу.

На капчу даётся 2 минуты и 3 попытки. Новую можно получить раз в 30 секунд.
Картинку видит только участник. После перезапуска бота кнопка панели продолжает
работать, но незавершённую проверку нужно начать заново.

## Настройка Discord

1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications)
   и получите токен в разделе **Bot**. Privileged Gateway Intents не нужны.
2. В **OAuth2 → URL Generator** выберите `bot` и `applications.commands`.
   Пригласите бота с правами **Manage Roles**, **View Channels**,
   **Send Messages**, **Embed Links** и **Attach Files**.
3. Создайте роль `Verified` без прав модератора. Поставьте роль бота выше неё.
4. Создайте канал верификации, доступный всем. В закрытых категориях запретите
   `@everyone` просмотр, а роли `Verified` разрешите. Синхронизируйте права каналов
   с категорией и проверьте, что другие роли новичка не дают доступ в обход проверки.
5. Включите режим разработчика в настройках Discord и скопируйте ID сервера и роли.

Бот только выдаёт роль — доступ к каналам нужно настроить самостоятельно.

## Установка и запуск

Нужен Python 3.11 или новее. В папке проекта создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его: `source .venv/bin/activate` на Linux/macOS
или `.venv\Scripts\Activate.ps1` в Windows PowerShell. Затем установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
DISCORD_TOKEN=токен_бота
GUILD_ID=id_сервера
VERIFIED_ROLE_ID=id_роли
```

Файлы `bot.py`, `captcha.py`, `challenges.py` и `.env` должны лежать в одной папке.
Все настройки находятся в `.env`.
Переменные окружения, заданные на хостинге, имеют приоритет над `.env`.

Запустите бота:

```bash
python bot.py
```

На сервере выполните `/verification-panel` и выберите канал. Команда доступна
только администратору. Она создаст сообщение с кнопкой проверки.

Бот работает, пока запущен процесс. Запускайте один экземпляр на один сервер.
Перед использованием проверьте выдачу роли и доступ к каналам обычным аккаунтом.
